# FenixCut v6

PWA de edição de vídeo (Android + iPhone): projetos guardados automaticamente, 52 efeitos, 36 transições, 20 estilos de legenda (jornal com caixa reta e letra normal), edição por IA, exportação até 4K. Tema magenta.

## Publicar
Carrega TODOS os ficheiros desta pasta para a raiz do repositório (novo: project.js). Settings -> Pages -> main / (root).

## Atualizar
Fecha a app, abre o link no navegador e recarrega 2 vezes. Os projetos guardados ficam no aparelho e não se perdem.

## Chave Groq (NUNCA no código)
Cola-a no separador Legendas e usa "Copiar link para configurar outro aparelho".

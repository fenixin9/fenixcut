# FenixCut v3

Editor de vídeo PWA (Android + iPhone): legendas automáticas (14 estilos, cores de destaque), 24 efeitos, 7 transições, texto animado e exportação 720p até 4K.

## Publicar no GitHub Pages
1. Carrega TODOS os ficheiros desta pasta para a raiz do repositório (substitui os antigos).
2. Settings -> Pages -> Deploy from a branch -> main / (root).
3. Abre https://SEU-UTILIZADOR.github.io/NOME-DO-REPOSITORIO/

## Atualizar
Fecha a app, abre o link no navegador e recarrega 2 vezes. Se continuar antiga: apagar dados do site.

## Chave Groq (NUNCA no código)
Este repositório é público: não escrevas a chave em ficheiros. Cola-a no separador Legendas e usa "Copiar link para configurar outro aparelho" para a levar para outros telemóveis.

# FenixCut

Editor de vídeo PWA (Android + iPhone): legendas automáticas editáveis, 24 efeitos, 7 transições, texto animado e exportação 720p até 4K.

## Publicar no GitHub Pages
1. Cria um repositório e carrega TODOS os ficheiros desta pasta para a raiz (não a pasta, o conteúdo).
2. Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.
3. Abre https://SEU-UTILIZADOR.github.io/NOME-DO-REPOSITORIO/

## Instalar no telemóvel
- Android (Chrome): menu ⋮ -> Instalar app.
- iPhone (Safari): Partilhar -> Adicionar ao ecrã principal.

## Atualizar
Depois de mudar ficheiros, altera `V` no sw.js (fenixcut-v1 -> fenixcut-v2).

# FenixCut v2

Editor de vídeo PWA (Android + iPhone): legendas automáticas editáveis, 24 efeitos, 7 transições, texto animado e exportação 720p até 4K.

## Publicar no GitHub Pages
1. No repositório, apaga os ficheiros antigos (ou deixa-os: vais substituir pelos novos com os mesmos nomes) e carrega TODOS os ficheiros desta pasta para a raiz (inclui o novo asr-worker.js).
2. Settings -> Pages -> Deploy from a branch -> main / (root).
3. Abre https://SEU-UTILIZADOR.github.io/NOME-DO-REPOSITORIO/

## IMPORTANTE ao atualizar
O telemóvel guarda a versão antiga. Depois de carregar os ficheiros novos: fecha a app, abre o link no navegador e recarrega 2 vezes. Se continuar antiga: Definições do navegador -> apagar dados do site.

## Instalar
- Android (Chrome): menu -> Instalar app.
- iPhone (Safari): Partilhar -> Adicionar ao ecrã principal.

## Legendas
Recomendado: chave grátis do Groq (console.groq.com/keys), colar no separador Legendas.

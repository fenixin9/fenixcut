# FenixCut v4

Editor de vídeo PWA (Android + iPhone): legendas automáticas (17 estilos, incl. recortes de jornal), edição por IA, 24 efeitos, 7 transições, texto estilizado e exportação 720p até 4K.

## Publicar no GitHub Pages
1. Carrega TODOS os ficheiros desta pasta para a raiz do repositório (substitui os antigos; há um novo: ai.js).
2. Settings -> Pages -> Deploy from a branch -> main / (root).

## Atualizar
Fecha a app, abre o link no navegador e recarrega 2 vezes. Se continuar antiga: apagar dados do site.

## Chave Groq (NUNCA no código)
Repositório público: não escrevas a chave em ficheiros. Cola-a no separador Legendas e usa "Copiar link para configurar outro aparelho".
